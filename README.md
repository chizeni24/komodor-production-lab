# Kubernetes Production Failure Lab

Technical demonstration for Komodor KAOP.

## Architecture
- Python HTTP API
- Redis dependency
- Kubernetes (kind)
- Grafana Cloud monitoring
- KAOP incident investigation and code review

## Planned scenarios
1. Cascading liveness probe failure
2. Gradual memory leak
3. Redis retry storm
4. CPU throttling
5. Kubernetes Service routing regression

## Objective
Demonstrate realistic Kubernetes incidents,
evidence-based root cause analysis, and
governed AI-assisted code review.
